# dnaftel.github.io

Personal academic website of Daniel Naftel. Plain static HTML/CSS, served by GitHub Pages (Jekyll disabled via `.nojekyll`).

- `index.html` — about page
- `research.html` — publications, working papers, and work in progress
- `style.css` — stylesheet
- `assets/` — photo, CV, papers, and figure thumbnails (`assets/figs/`)

The previous Jekyll site is preserved on the branch `backup-original-site-2026-09-11` and the tag `original-site-2026-09-11`.
